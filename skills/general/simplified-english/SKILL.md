# How to write these documents (ASD-STE100)

Write all documents in Simplified Technical English (ASD-STE100).
This makes the documents easy to read for all persons on the team.
It also makes the documents easy to read for persons who do not speak English
as a first language.

## Words

1. Use simple, common words. Use one word for one meaning.
2. Use the same word each time you write about the same thing.
3. Do not use product jargon. If you must use a technical name, tell the reader
   what it means the first time.
4. Do not use slang. Do not use idioms. Do not use words that make a picture,
   such as "north star" or "rabbit hole", unless you give the meaning.
5. Write "for example" and not "e.g.". Write "that is" and not "i.e.".
   Do not write "etc.".
6. Write "before" and not "prior to". Write "to" and not "in order to".
   Write "about" and not "approximately". Write "help" and not "assist".
   Write "use" and not "utilize". Write "make sure" and not "ensure".

## Sentences

1. Keep instruction sentences to 20 words or less.
2. Keep other sentences to 25 words or less.
3. Write one instruction in one sentence.
4. Start an instruction with a verb: "Ask the user…", "Write the goal…".
5. Use the active voice. Write "the team measures the result".
   Do not write "the result is measured by the team".
6. Use simple tenses: present, past, and future.
7. Do not use verb forms that end in "-ing" as a name for a thing.
   Write "how to research" and not "researching".
8. Use "the" and "a" where you can.
9. Write "must" for a requirement. Write "do not" for a prohibition.

## Text structure

1. Keep a paragraph to 6 sentences or less.
2. Use a numbered list for steps. Use a bullet list for items.
3. Use no more than 3 words together as one name for a thing.
4. Give each list item one idea.
5. Use tables for data. Keep each cell short.

## Check before you finish

- Read each sentence. Count the words. Make long sentences shorter.
- Find each word that is not common. Change it or explain it.
- Find each "-ing" word. Change it if it is the name of a thing.
- Find each passive sentence. Change it to the active voice.
